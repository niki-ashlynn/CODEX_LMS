# 📚 Codex — Library Management System

**A Web-Based Library Management System | 2025–2026**

Codex is a database-driven Library Management System developed using **PHP and MySQL**. The project focuses on managing library resources, book borrowing, returns, and member activities through a centralised web application.

The system provides separate functionalities for administrators and library members, allowing users to interact with library resources while supporting day-to-day library management.

## 📌 Project Overview

Codex was developed to simplify library operations by replacing manual record-keeping with a structured digital system.

The application allows members to browse and search for books, manage borrowing activities, and leave book reviews. Administrators can manage library resources, monitor borrowing records, and handle fines.

The project demonstrates the practical application of web development, relational databases, and backend programming in building a management system.

## 🎯 Project Objectives

- Develop a centralised platform for managing library resources and member activities.
- Simplify the book borrowing and returning process.
- Organise book information using structured categories.
- Maintain borrowing records and track fines.
- Provide different functionalities for administrators and members.
- Apply database management concepts to a real-world scenario.

## ✨ Key Features

### 1. User Roles — Admin & Member

The system supports two main user roles:

**Administrator**
- Manage library resources and book information.
- Organise books into categories.
- Monitor book borrowing and returning activities.
- Manage library fines.

**Library Member**
- Browse and search for books.
- Borrow and return books.
- View book information.
- Submit book reviews.

### 2. Book Management

Codex provides a structured way to organise library resources.

- Maintain book information.
- Categorise books for easier organisation.
- Support searching and browsing.
- Manage book availability through borrowing activities.

### 3. Borrowing & Returning

The system supports the management of book loans and returns.

- Record borrowing activities.
- Manage book returns.
- Maintain borrowing information.
- Support the tracking of outstanding loans.

### 4. Fine Management

The fine management functionality helps track penalties associated with library borrowing.

- Manage fine information.
- Associate fines with relevant borrowing activities.
- Support administrators in monitoring outstanding fines.

### 5. Book Reviews

Members can provide feedback on books through the review functionality.

- Submit reviews for books.
- Support member engagement.
- Provide additional information for other readers.

## 🗄️ Database Management

MySQL is used to support the storage and organisation of library information.

The project applies relational database concepts to connect different aspects of library operations, including:

- Books and categories
- Library members
- Borrowing and returning records
- Fines
- Book reviews

The database-driven approach helps organise information and supports retrieval and management of library records.

## ⚙️ System Workflow

**Member Workflow**

**Administrator Workflow**

1. Access administrative functionalities.
